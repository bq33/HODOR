# Security Policy

## Reporting a Vulnerability

If you discover a security issue in HODOR or related examples, please report it responsibly.

- Do not open public issues for sensitive vulnerabilities
- Email: [your email or placeholder]
- Include reproduction steps and impact if possible

## Scope

HODOR is a reference framework and does not contain production systems.

However, we encourage responsible disclosure for:
- example configurations
- patterns that could be misused
- documentation gaps that create risk

## Response

We will review and respond as quickly as possible.
